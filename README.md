# Screnbites media

Public media host for the @screnbites Instagram page. Posts are published through Windsor.ai,
which needs a public URL for each image or video.

- `media/feed/` — feed images and carousel slides (JPEG, 1080×1350)
- `media/reels/` — Reels (MP4, 1080×1920)
- `media/profile_picture.jpg` — profile picture
- `content.json` — captions and card text for every post
- `manifest.json` — file list per post
- `schedule.json` — posting calendar and status
